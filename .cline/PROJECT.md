# CineCast

Plataforma brasileira de audiovisual.

Objetivo:

Centralizar:

- Produções
- Chamadas de elenco
- Chamadas de equipe
- Candidaturas
- Networking

Stack:

- Next.js
- TypeScript
- TailwindCSS
- Supabase
- PostgreSQL
- Vercel

Regras:

- Nunca apagar funcionalidades.
- Nunca alterar banco sem explicar.
- Sempre manter responsividade.
- Priorizar UX.
- Priorizar acessibilidade.
- Utilizar componentes reutilizáveis.
