# 🎬 Cine Cast — Database

Arquivos de schema e migrations do banco de dados PostgreSQL.

## Migrations

Gerenciadas com Prisma ORM. Veja `../docs/DATABASE.md` para documentação completa.

```bash
cd ../backend
npx prisma migrate dev
```

## Seeding

Dados de exemplo para desenvolvimento:

```bash
cd ../backend
npx prisma db seed
```
